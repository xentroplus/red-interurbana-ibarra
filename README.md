# Red Interurbana TS Ibarra

PWA para consulta interactiva de la Red Interurbana de la Técnica Sucursal Ibarra.

## Versión
v1.0

## Funciones iniciales
- Lectura del KMZ inicial.
- Indicadores de rutas, trazados, nodos, mangas y provincias.
- Cobertura territorial.
- Mapa interactivo con capas.
- Consulta de rutas e infraestructura.
- Carga manual de un nuevo KMZ en el navegador.

> La información del KMZ se procesa localmente en el navegador.
